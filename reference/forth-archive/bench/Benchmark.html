Benchmark Results

Here are some speed comparisons of Misty Beach Forth versus some other Forth implementations. Note that Misty Beach Forth has several reported times because I ran it under several environments. The best result is running under Netscape 4.x. Using this environment, Misty Beach Forth is as fast as the native Win32Forth at stack operations and about half as fast at variable operations.

All the Misty Beach Forth benchmarks were run with Misty Beach Forth configured as it is launched, which means that control optimizations and small word unrolling are turned on but peephole optimization is turned off. With peephole optimization on, the variable operation benchmark runs about 3 times faster, but peephole optimization is not fully implemented, so I'm leaving it turned off for these benchmarks.

Obviously, this is a far from complete benchmark of Forth implementation performance. I have some pointers to better benchmarks, but haven't downloaded and run them yet. As I find and run better benchmarks, I'll add them here.

Stack operations

: INNER 10000 0 DO 34 DROP LOOP ;
: OUTER 10000 0 DO INNER LOOP ;
OUTER
This is a variation of a benchmark posted by Bernie Mentink. See F21 and F*F by Jeff Fox for a discussion and results from other Forths. Note that the original benchmark only loops to 1000 in both loops, so the numbers reported by Jeff Fox must be multiplied by 100 to compare them to these.
Forth Implementation Time in seconds
Jax Forth V1.25(1) 144
Misty Beach Forth V0.30 under Netscape 3.x(2) 92
Misty Beach Forth V0.30 under Internet Explorer 3.x(3) 67
Misty Beach Forth V0.30 with Symantec JIT 2.0.54(4) 59
Win32Forth V3.2(5) 59
Misty Beach Forth V0.30 under Netscape 4.x(6) 54
LMI Forth V1.01 (no optimizations) (7) 27
LMI Forth V1.01 (optimized with NCC and COMPILE:) (8) 7

  • Footnotes
  1. Jax4th for Windows-NT Revision 1.25 on a Pentium-90 with 64 MB RAM running Windows-NT 4.00.
    Jax4th is a GNU copylefted 32-bit Forth by Jack J Woehr. Jack provides the following comment:
    Jax4th is not an optimizing compiler targeted at professional development. The author did not dream of providing in two hundred (200) hours of his time a freeware Forth to compete with professional systems which required thousands of hours of programmer time to complete.

  2. Running Netscape Navigator 3.01 on a Pentium-90 with 64 MB RAM running Windows-NT 4.00.
    This version on Netscape comes with Borland's JIT (AppAccelerator) compiler for Java applets.

  3. Running Microsoft Internet Explorer 3.01 with one patch on a Pentium-90 with 64 MB RAM running Windows-NT 4.00.
    This version of Internet Explorer comes with Microsoft's JIT compiler. The patch is available at http://www.microsoft.com/java and fixes some known bugs that were preventing Misty Beach Forth from running.

  4. Running Symantec Visual Cafe 1.0d with JIT 2.0.54 on a Pentium-90 with 64 MB RAM running Windows-NT 4.00.

  5. Win32Forth V3.2 build 0819 built July 26th 1996 running on a Pentium-90 with 64 MB RAM running Windows-NT 4.00.
    Win32Forth is a public domain 32-bit Forth by Andrew McKewan, Tom Zimmer, Jim Schneider, Robert Smith, Y.T. Lin and Andy Korsak.

  6. Running Netscape Navigator 4.x on a Pentium-90 with 64 MB RAM running Windows-NT 4.00.
    This version on Netscape comes with Symantec's JIT (AppAccelerator) compiler for Java applets. Obviously, this is a faster than the JIT supplied with Visual Cafe 1.0d

  7. LMI Forth for Windows 1.01 on a Pentium-90 with 64 MB RAM running Windows-NT 4.00.
    LMI Forth is a commercial 16-bit Forth by Laboratory Microsystems Inc.

  8. LMI Forth for Windows 1.01 on a Pentium-90 with 64 MB RAM running Windows-NT 4.00.
    LMI Forth is a commercial 16-bit Forth by Laboratory Microsystems Inc. LMI has some options for speeding up code and this benchmark is generated using the NCC (Native Code Compiler) option and then using the COMPILE: word in place of :.
